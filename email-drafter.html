Gmail Integration (Optional)
Google OAuth Client ID Not set
To enable "Save as Gmail Draft", you need a Google OAuth 2.0 Client ID.
Quick setup:
1. Go to Google Cloud Console → APIs & Services → Credentials
2. Create an OAuth 2.0 Client ID (Web application type)
3. Add file:// and your local server URL as authorized JavaScript origins
4. Enable the Gmail API for your project
5. Paste the Client ID above

Without this, you can still copy emails and paste into Gmail manually.
